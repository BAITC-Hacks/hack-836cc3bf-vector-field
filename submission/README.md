# Проверенные результаты исходного кейса

- `nodes_roles.csv`: все 2248 gid, включая 19 изолированных seed.
- `clusters.csv`: 105 рассчитанных кластеров.
- `top_nodes.csv`: 100 уникальных узлов, priority DESC / gid ASC.
- `manifest.json`: SHA-256 и версия проверенного snapshot.
- `backup.zip`: эти CSV, snapshot и production UI в путях `pipeline/out/` и `frontend/dist/`.

Источник — три Parquet в `case/data (1)/data`. Результаты рассчитаны общими правилами v0; scores не являются вероятностями виновности. Полный повторный запуск, ограничения и масштабирование — в корневом README. Пятиминутный показ и точные команды восстановления — `docs/DEMO.md`. Текущий gate — `integration/FINAL_GATE.md`.

Ключи, модельные ответы, зависимости и банковские действия в резервный пакет не входят. После восстановления запуск `python scripts/demo.py --skip-pipeline --no-ai` обслуживает локальный UI/CSV/API без внешних вызовов. При смене данных пересчитать все файлы.
